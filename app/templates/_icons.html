{# ========================================================================== SVG icon sprite (docs/UX.md section 3). Included once by base.html; every other template references a symbol with ``. This replaces the emoji the interface used to draw with: an emoji is rendered by the platform font, so the same "clipboard" was blue on Windows and grey elsewhere, none of them matched the terracotta palette, and screen readers announced the Unicode name of a decoration. Stroke icons inherit `.icon`'s stroke from CSS. The two solid symbols (paw, sparkle) are used with `.icon--filled`, which swaps stroke for fill. Geometry is on a 24x24 grid so a symbol lines up with text at any size. ========================================================================== #}
